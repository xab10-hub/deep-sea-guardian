# 守护光源 · 深海

一条 AI 主导开发的深海下潜小游戏。单文件 HTML，浏览器打开即玩。

## 下载

- `守护光源-深海-电脑网页版-v9.3.1.html` —— 最新版（含「歌唱海峡 · 歌鲸」）
- `守护光源-深海-电脑网页版-v9.1.2.html` —— 稳定版

打开网页后点上面的文件名即可开始；或右键另存到本地，双击 HTML 离线玩。

## 玩法

- 鼠标/键盘移动，吸收光点维持生命
- 击杀鱼群回光，Q 释放鲸落清场
- 9,600–10,400m「歌唱海峡」歌鲸拦路（三阶段）
- 20,000m 终章 Boss「渊心灯王」，击败后进入第二章「亚特兰蒂斯」
